## Quick Local Test (Before Uploading)

1. Double-click `index.html` → opens in Chrome
2. Click "Free Quote" button → goes to quote.html ✓
3. Click any phone number → opens dialer ✓
4. Click any service card "Learn more" → goes to detail page ✓
5. Resize browser narrow → mobile layout works ✓

If all 5 work, you're ready to deploy.

## Vercel Upload — Three Steps

1. **vercel.com** → log in → "Add New..." → "Project"
2. Drag this folder into Vercel (or click "Browse")
3. Click "Deploy" → live URL appears in 30 seconds

Vercel auto-detects this as a static site. No build settings needed.

## After Deployment

- **Connect your domain:** Project Settings → Domains → add `envirocarellc.com` or `new.envirocarellc.com`
- **Connect the form:** Sign up at formspree.io, get a form endpoint, paste into `quote.html`
- **Add Google Analytics:** I'll provide a paste-in tracking code when you're ready
